# Analysis engine

`stockfish-19-lite-single.js` / `.wasm` — Stockfish.js 19.0.1 "lite, single-threaded" build
by Nathan Rugg / Chess.com, from https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1.

Used for game review, the eval bar, the what-if sandbox and puzzle grading.
The bots still play with Stockfish 10 from the CDN so their difficulty tuning is unchanged.
